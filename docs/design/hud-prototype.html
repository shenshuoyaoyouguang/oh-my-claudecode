区域分隔层级（ioGrouping=on，灭 P1-10）

I: O: S: 区域标签（dim + 冒号）前置强化区域边界；

区域内元素用 |（L1 元素分隔，细线）；区域之间用 ╎（L2 区域分隔，U+257E 粗实线，1 列）。

同 3 列宽，靠字形 + 区域标签区分层级。safeMode 下 ╎→|，层级仅靠区域标签表达（R-SEP-4）。

标签语法 & 阈值（R-LABEL-1 / R-THRESH-1）

标签语法（唯一）dim(label:) + colored(value) —— 标签永远 dim、冒号必带、无空格；值才着色；同一元素内不允许两个彩色标签（R-COLOR-2）。无标签例外：[OMC]、callCounts 图标、thinking 符号、区域标签 I:/O:/S:（R-LABEL-2）。
percent 阈值THRESHOLDS.percent = { warn: 70, critical: 90 } —— context / rate limits / enterprise cost / payload 共用（context 临界从 85 上调到 90，对齐 limits）。
进度色 ≠ 危险色todos / background 容量：≥80% GREEN / ≥1% CYAN / 0 DIM（无黄，R-THRESH-2）。
时长异常agent / session 时长：<2m GREEN / 2-5m YELLOW / >5m RED（R-THRESH-3）。
bold 白名单仅 3 类：① update 提醒 ② warning banner 标题 ③ critical 关键值。一行 ≤1 处 bold；[OMC] 品牌非 bold（R-WEIGHT-1/3）。
动作词统一COMPRESS? → ctx:82%! compact，与详情行 run /compact 同一动作词（R-LABEL-4，灭 P1-04）。
